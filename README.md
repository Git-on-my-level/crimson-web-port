# Crimson Web Port

Live demo: https://git-on-my-level.github.io/crimson-web-port/

## Assets

This repo ships with a lightweight fake asset pack in `assets_fake/` that is copied into `public/assets` by default.

- Default (fake assets): `npm run dev` / `npm run build`
- Real assets (requires `ignored_assets/`): `npm run dev:real` / `npm run build:real`
